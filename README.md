# 🎓 Student Management System

A simple Student Management System developed using **Python and MySQL** to manage student information and records.

## 📌 Features

* Add student records
* Update student records
* View student records
* Manage student information
* Store student data in MySQL

## 🛠️ Technologies Used

* Python
* MySQL

## 📂 Project Files

* `main.py` – Main application program
* `database.py` – Database connection and database-related operations

## 🎯 Project Objective

The main objective of this project is to create a simple database-based application for managing student information efficiently.

* Add a graphical user interface
* Add student search functionality
* Add authentication
* Improve validation and error handling
